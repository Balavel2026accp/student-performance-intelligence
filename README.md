# Student Performance Intelligence

A role-based academic performance analytics platform.

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL
- Cloud: AWS EC2
- CI/CD: GitHub Actions

## Applications

### Admin Portal
- Student and subject management
- Examination result management
- Five-year performance analytics
- Reporting and data export

### Student Portal
- Personal academic information
- Published subject toppers
- Published annual rankings
- Year-wise performance statistics
